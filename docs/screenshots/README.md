# VELYXORA — UI screenshots

All images are WebP, captured at 1440×900 (desktop) and 390×844 (mobile) from a
local development build served by `npm run dev`.

Regenerate them with the Playwright MCP browser after logging in as an
administrator (the admin dashboard and account screens require a session).
